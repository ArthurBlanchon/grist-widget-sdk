---
title: "useGrist"
description: "The widget's one object for Grist: connection, records, mapping, writes, options, linking and REST."
---

```ts
function useGrist<TRow = Record<string, unknown>, TMapped = Record<string, unknown>>(
  options?: UseGristOptions,
): UseGristResult<TRow, TMapped>
```

Inside `<GristWidgetProvider>` (what `mountGristWidget()` renders),
`useGrist()` reads the provider's connection and ignores `options`. Outside
one, it uses a page-wide connection made with the first caller's `options`.

Every call reads one store through `useSyncExternalStore`: a component
re-renders when a value changes. Every method is referentially stable for the
widget's lifetime, so it is safe in effect dependencies; the result object
itself is new on every change, so depend on its members, not on it.

## `UseGristOptions`

```ts
type UseGristOptions = GristReadyOptions & {
  suppressAlerts?: GristSdkAlertKind[] // alert kinds mountGristWidget() never shows, e.g. ["section-not-linked"]
  schema?: StandardSchema              // extra rules for the mapped records (zod 4, valibot, arktype…)
}
```

`GristReadyOptions` is what Grist's `ready()` takes: `requiredAccess`
(`"none"`, `"read table"`, `"full"`), `columns` to map, `allowSelectBy`,
`hasCustomOptions`, `onEditOptions`. See
[Provider & boundary](/docs/sdk/api/provider-boundary).

## `UseGristResult<TRow, TMapped>`

The access column is the least access a member needs. A member that needs
`"full"` fails in a widget that asked for less, and the alert above the
widget says what to change in Grist.

### Connection

| Member | Type | Notes |
| --- | --- | --- |
| `status` | `"booting" \| "ready" \| "unavailable" \| "error"` | `"error"` too when Grist grants less access than declared. |
| `error` | `string \| null` | Why the widget can't run, else `null`. |
| `reload()` | `() => Promise<void>` | Calls `grist.ready()` again and re-reads mappings. |
| `theme` | `"light" \| "dark" \| null` | Grist's theme, `null` until Grist sends it. |

### Selection and mapping (`"read table"`)

| Member | Type | Notes |
| --- | --- | --- |
| `record` | `GristRowRecord<TRow> \| null` | The selected row, raw column ids. |
| `records` | `GristRowRecord<TRow>[] \| null` | The section's rows (what its filters show). |
| `mode` | `"empty" \| "row" \| "new-row"` | No row, a row, or the add-row placeholder. |
| `currentTableId` | `string \| null` | The section's table. |
| `mappings` | `GristWidgetColumnMap` | Declared name → the Grist column id(s) mapped to it. |
| `columnMappingStatus` | `{ ok, pending?, missing, emptyMultiples }` | `pending` until Grist reports mappings; `ok` once every required column is mapped. |
| `mappedRecord` | `TMapped \| null` | The selected row under declared names, as Grist's `mapColumnNames` builds it (`id`, each mapped column, a list for `allowMultiple`), each cell the value its declared type promises; `null` while a required column isn't mapped. See [Typed reads](/docs/sdk/guide/typing). |
| `mappedRecords` | `TMapped[] \| null` | Every row of the section, like `mappedRecord`. |
| `cellIssues` | `readonly GristCellIssue[]` | The mapped cells that don't match their declared type (or `schema`): `{ rowId, column, message, value }`. Such a cell is `null` in the mapped records. |
| `resolveMappedColumnId(name)` | `(name: string) => string` | The Grist column id mapped to `name`, or `name`. |
| `mapBack(patch)` | `(patch: Partial<TMapped>) => Record<string, unknown>` | A patch under declared names as real column ids, each value encoded for its declared type (a list to `["L", ...]`, a `Date` to seconds); `allowMultiple` columns can't be written back and are skipped (an alert names them). |
| `updateRecord(patch)`, `updateRecord(rowId, patch)` | `Promise<void>` | Writes a patch under declared names to the selected row (or to `rowId`): `mapBack` and `table.update` in one call. Rejects when no row is selected and none is given. |
| `addRecord(patch)` | `Promise<number>` | Adds a row to the section's table from a patch under declared names; resolves to its row id. |

### Reads

| Member | Access | Notes |
| --- | --- | --- |
| `fetchRows(options?)` | `"read table"` | The section's rows (what its filters show, in its order), each `{ id, ...cells }` under real column ids. |
| `fetchRows(tableId, options?)` | `"full"` | Any table's rows, in Grist's order (`order: "id"` or `"none"` to change it; `columns` to decode with the [replica's column metadata](/docs/sdk/design/replica-document)). |
| `fetchRows(…, { columnar: true })` | as above | Grist's column-oriented payload (`{ id: [...], Name: [...] }`) instead. |
| `listTables(options?)` | `"read table"` | Table ids; Grist's own tables only with `{ includeSystem: true }`. |
| `listColumns(tableId, options?)` | `"full"` | Column ids, types, labels, formulas. |

### Writes (`"full"`)

| Member | Notes |
| --- | --- |
| `table` | `create`, `update`, `upsert`, `destroy` on the section's table (single or bulk). |
| `getTable(tableId)` | The same, on any table. |
| `applyActions(actions, options?)` | User actions applied together, e.g. schema changes with the [user action builders](/docs/sdk/api/helpers#user-actions). |
| `actionStatus` | `"idle" \| "running" \| "error"`: the last write. |
| `actionError` | The last failed write's message, else `null`. |

### Widget options

| Member | Access | Notes |
| --- | --- | --- |
| `widgetOptions` | `"read table"` | The options Grist stores for this widget, `null` until it sends them. |
| `setWidgetOptions(options)` | `"full"` | Replaces them. |
| `patchWidgetOptions(patch)` | `"full"` | Merges `patch` into them. |

### Linking (`"read table"`)

| Member | Notes |
| --- | --- |
| `setCursorPosition(pos)` | Moves Grist's cursor (`{ rowId?, field?, sectionId? }`). |
| `setLinkedRowSelection(rowIds \| null)` | The rows the widget selects, for sections linked to it (`allowSelectBy: true`). |

### Attachments and REST (`"full"`)

| Member | Notes |
| --- | --- |
| `getAttachmentUrl(id, options?)` | A download URL carrying an access token. |
| `fetchAttachmentBlob(id, options?)` | `{ blob, contentType }`. |
| `uploadAttachment(file, options?)` | `{ ids, firstId }`: put them in an Attachments cell with `gristAttachmentCellValue()`. |
| `fetchWithAuth(path, init?)` | `fetch()` against the document's REST API (`/records`, `/sql`, …) with an access token. Only the document's own Grist instance gets the token: another origin throws. |

`options.readOnly` asks for a read-only token on the download and REST
members.

### Deprecated

Still on the result in 0.6, warning once in development; removed in 1.0.
See [Deprecated names](/docs/sdk/api/deprecated).

| Member | Instead |
| --- | --- |
| `isReady` | `status === "ready"` |
| `isAvailable` | `status`: `"unavailable"` outside Grist, `"booting"` while connecting |
| `fetchSelectedTable(options?)` | `fetchRows({ columnar: true })`, or `fetchRows()` for rows |
| `fetchTable(tableId)` | `fetchRows(tableId, { columnar: true })`, or `fetchRows(tableId)` for rows |
| `fetchTableRows(tableId, options?)` | `fetchRows(tableId, options)` |

## Outside a provider

`useGristOptional()` returns `null` outside `<GristWidgetProvider>`, for a
component that also works without Grist. `useGristContext()`, which threw
there, is deprecated: `mountGristWidget()` always renders the provider, so
`widget.useGrist()` (or `useGrist()`) is enough.

## Examples

### Selection + write

```tsx
import { defineGristWidget } from "grist-widget-sdk"

export const widget = defineGristWidget({
  requiredAccess: "full",
  columns: [{ name: "Done", type: "Bool" }],
})

function Toggle() {
  const w = widget.useGrist()
  if (w.mode !== "row" || !w.mappedRecord) return null
  const done = w.mappedRecord.Done ?? false

  return (
    <button disabled={w.actionStatus === "running"} onClick={() => w.updateRecord({ Done: !done })}>
      {done ? "Mark not done" : "Mark done"}
    </button>
  )
}
```

### Status + retry

```tsx
function StatusLine() {
  const { status, error, reload } = useGrist()

  if (status === "ready") return null
  if (status === "error") return (
    <p>Error: {error} <button onClick={reload}>Retry</button></p>
  )
  if (status === "unavailable") return <p>Open this widget inside a Grist document.</p>
  return <p>Connecting…</p>
}
```

### Schema mutation

```tsx
import { gristAddColumnAction, gristRenameColumnAction } from "grist-widget-sdk/actions"

async function migrate(w: ReturnType<typeof useGrist>) {
  await w.applyActions(
    [
      gristAddColumnAction("Tasks", "Priority", { type: "Choice" }),
      gristRenameColumnAction("Tasks", "Title", "Name"),
    ],
    { desc: "Add Priority column" },
  )
}
```

### REST

```ts
const r = await w.fetchWithAuth("/sql", {
  method: "POST",
  body: JSON.stringify({ sql: "SELECT id, Name FROM Tasks LIMIT 5" }),
})
const data = await r.json()
```
