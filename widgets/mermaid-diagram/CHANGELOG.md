# Changelog

What changed in each version, for the people using the widget. Newest first.

## 0.1.1 (2026-11-15)

- Diagrams are always laid out by Dagre. One whose front matter asks for the ELK layout is drawn with Dagre: ELK is no longer shipped with the widget, its licence being off the catalog's allow list.

## 0.1.0 (2026-11-15)

First release. A Mermaid diagram written in the selected row's cell, or a flowchart drawn from the rows' From and To columns.
