This builds a widget that shows the selected task of a Grist table and
marks it done. You need Node 22, [pnpm](https://pnpm.io/installation), git
and a GitHub account.

## 1. Scaffold it

```bash
npm create grist-widget my-widget
cd my-widget
pnpm dev
```

The command writes the widget, installs its dependencies with pnpm, and
makes the first commit on `main`, with a `dev` branch ready.

Open `http://localhost:5173/demo/index.html`: Grist itself, running in
your browser, with a document and your widget in it. Edits reload in
place. Nothing is saved, and nothing leaves your machine.

## 2. Declare what it reads

The widget is `src/app/App.tsx`. Its declaration says what it asks Grist
for:

```ts
import { defineGristWidget } from "grist-widget-sdk"

export const widget = defineGristWidget({
  title: "Task",
  description: "Mark the selected task done.",
  requiredAccess: "full",
  columns: [
    { name: "Title", type: "Text" },
    { name: "Done", type: "Bool" },
  ],
})
```

- **`columns`** are the widget's own names. In Grist, the person maps a
  column of their table to each: their `Task name` to your `Title`, say.
  Until they do, the widget shows "Map your columns".
- **`requiredAccess`** is `"full"` because the widget writes. A widget
  that only reads asks for `"read table"`.

## 3. Read the selected row

```tsx
import { defineGristWidget } from "grist-widget-sdk"

export const widget = defineGristWidget({
  requiredAccess: "full",
  columns: [
    { name: "Title", type: "Text" },
    { name: "Done", type: "Bool" },
  ],
})

export default function App() {
  const w = widget.useGrist()
  if (w.mode === "new-row") return <p>Add the row in Grist, then select it.</p>
  if (!w.mappedRecord) return <p>Select a task in Grist.</p>
  return <h1>{w.mappedRecord.Title || "Untitled"}</h1>
}
```

`widget.useGrist()` is typed from the declaration: `w.mappedRecord.Title`
is a `string | null`, `Done` a `boolean | null`. `w.mode` says whether a
row is selected, none is, or the new-row line is.

## 4. Write it back

```tsx
import { defineGristWidget } from "grist-widget-sdk"

export const widget = defineGristWidget({
  requiredAccess: "full",
  columns: [
    { name: "Title", type: "Text" },
    { name: "Done", type: "Bool" },
  ],
})

export default function App() {
  const w = widget.useGrist()
  if (!w.mappedRecord) return <p>Select a task in Grist.</p>
  const { Title, Done } = w.mappedRecord
  return (
    <main>
      <h1>{Title || "Untitled"}</h1>
      <button disabled={w.actionStatus === "running"} onClick={() => w.updateRecord({ Done: !Done })}>
        {Done ? "Mark as not done" : "Mark as done"}
      </button>
    </main>
  )
}
```

`w.updateRecord` writes the selected row under your names, into the
column the person mapped. If Grist refuses the write, an alert above the
widget says why.

## 5. Test it

`src/app/App.test.tsx` runs the widget against an emulated Grist: a table
built from the declared columns, mapped, with the rows you give.

```tsx no-check
import { expect, it } from "vitest"
import { fireEvent, renderWithGrist, screen, waitFor } from "grist-widget-sdk/emulator/testing"

import App, { widget } from "./App"

it("marks the selected task done in Grist", async () => {
  const { emulator } = renderWithGrist(<App />, { widget, rows: [{ Title: "Buy milk", Done: false }] })
  fireEvent.click(await screen.findByRole("button", { name: "Mark as done" }))
  await waitFor(() => expect(emulator.state.tables.get("Table1")!.rows[0]).toMatchObject({ Done: true }))
})
```

```bash
pnpm test
```

## 6. See it in your own Grist

Create an empty GitHub repository, then push both branches:

```bash
git remote add origin https://github.com/<you>/my-widget.git
git push -u origin main
git push origin dev
```

The push to `main` runs the deploy workflow once, which creates the
`gh-pages` branch. Point GitHub Pages at it (**Settings → Pages → Deploy
from a branch → `gh-pages`**); if the workflow can't push, allow it
(**Settings → Actions → General → Read and write permissions**).

Your `dev` branch is then served at
`https://<you>.github.io/my-widget/dev/`. In a Grist document, add a
**Custom widget** section, paste that URL, and map your columns. Every
push to `dev` reloads it there.

## 7. Release it

Once it works on `/dev/`, release it:

```bash
pnpm release minor
git push origin dev
```

That raises the version and writes the changelog entry. Open the pull
request from `dev` into `main` (the command prints its link), and merge
it once its checks are green. The workflow publishes
`…/my-widget/v<version>/`, which never changes, and moves
`…/my-widget/latest/` to it: paste one of those into the documents that
use the widget.

## 8. Protect the repository

After that first release:

```bash
pnpm exec create-grist-widget protect
```

It uses the GitHub CLI (`gh auth login` first). From then on, `main`
changes only through a pull request with green checks, and neither
branch can be force-pushed or deleted.
