One page for daily reference once you understand the
[mental model](/docs/quickstart/concepts). Every TypeScript example below is the full
**`WidgetApp.tsx`** from `examples/<id>/`, deployed standalone at
`/examples/<id>/latest/` and running in a real Grist at
`/examples/<id>/demo/`.

The deployed example wraps it in `GristWidgetProvider` and `GristBoundary`;
snippets show only `WidgetApp` (and `GRIST_OPTIONS`).

| `"row"` | A real row is selected. `w.record` and `w.mappedRecord` are populated. |
| `"new-row"` | The user is on the add-row placeholder. |
