# Changelog

This file is a pointer, not a log. Released history is generated by
[Changesets](https://github.com/changesets/changesets), per published package:

- [`packages/core/CHANGELOG.md`](./packages/core/CHANGELOG.md) — `grist-widget-sdk`
- [`packages/create-grist-widget/CHANGELOG.md`](./packages/create-grist-widget/CHANGELOG.md) — `create-grist-widget`

Both are also mirrored on their [GitHub Releases](https://github.com/ArthurBlanchon/grist-widget-sdk/releases).

To record a user-visible change, run `pnpm changeset` and commit the
generated `.changeset/*.md` file — see [`AGENTS.md`](./AGENTS.md). A PR that
touches published-package source without one fails CI
(`scripts/check-changeset.sh`).

The hand-curated project history that predates changesets is archived at
[`docs/history/CHANGELOG-pre-changesets.md`](./docs/history/CHANGELOG-pre-changesets.md).
